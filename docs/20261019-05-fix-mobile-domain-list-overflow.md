# 域名列表移动端横向溢出修复

- 文档编号：20261019-05
- 关联缺陷：VIDE-31 / DEF-002
- 影响范围：`/#/domain/list` 的 375px 移动视口

## 问题

全局样式为 `html`、`body` 和 `#app` 设置了 `min-width: 1200px`，导致手机端文档宽度固定为 1200px，页面内容从初始视口横向裁切。

## 修复

- 移除全局 1200px 最小宽度，恢复视口宽度布局。
- 为布局主区域设置 `min-width: 0`，使 flex 子项能在窄屏收缩，并将超宽内容限制在内容区域内滚动。
- 域名列表在窄屏下将新增与搜索操作换行；表格保留列信息，在列表区域内横向滚动。
- 移动端页头隐藏非必要文字、主题切换与面包屑，保留导航下拉与账户入口，避免页头自身撑宽页面。
- 小屏侧栏从文档流移为带遮罩的导航抽屉，可由页头按钮打开、遮罩或关闭按钮关闭；切换路由后自动收起。
- 工具栏与分页在小屏下自动换行并保留按钮文字，避免逐字竖排。

## 验证

在 `domain-admin-web` 执行 `npm ci && npm run build`，生产构建成功。复验时请使用 375×812 和 1440×900 视口访问 `/#/domain/list`，确认 `document.documentElement.scrollWidth === window.innerWidth`，且桌面表格与操作区显示不变。
